# 问题采集表（用户问题 ↔ 来源缺口）

**版本**：v0.1（2026-10-21）

本文件说明「怎么向别人采集真实问题、采集什么、以及**为什么采集顺序会影响结论是否成立**」。
它同时是一份可以直接发出去的问卷——第 2 节整段可以复制。

---

## 0. 为什么要有这份表（自己看）

- 目标不是"多收几个问题"，而是拿到**需求分布**：别人真正要问的是什么、需要哪类来源、现在缺什么。
- 它是 [backlog-rice.md](backlog-rice.md) 里所有 Reach 假设的验证工具，也是 [prd-feedback-loop.md](prd-feedback-loop.md) 的前置。
- **目标量：5 人 × 5 题 = 25 题。** 不足 15 题时只做描述，不报比例——沿用项目自己的判据。
- 收完**不要立刻补资料**：先看分布，再按缺口频次决定补什么。

## 1. ⚠️ 两阶段采集（顺序不能换）

| 阶段 | 做什么 | 收到什么 |
| --- | --- | --- |
| **阶段 1（无提示）** | 先**不提**这个系统、不展示资料清单、不让试用 | 真实需求分布 |
| **阶段 2（给简介后）** | 再告诉他系统有什么、能答什么 | 可用性问题、演示候选 |

**为什么必须先做阶段 1**：一旦对方知道"库里有什么"，他问的问题会天然偏向库里已有的资料。
用这种题去算"缺什么来源"，是循环论证——你只会得到「缺口 = 我本来就有的东西」这个结论。

两阶段的题**必须分别标注**，缺口统计只用阶段 1。阶段 2 的题对演示有用，对补资料没用。

> 所以你的直觉（"别人得知道大概情况才能问"）是对的，但**它属于阶段 2**。
> 阶段 1 问的是另一件事：**在过去，你为了查一个事实，真的去翻过什么。**

## 2. 发给对方的话（整段可复制）

> 打扰一下，帮我个忙，大概 15 分钟 🙏
>
> 我在做一个**设计知识库问答助手**的项目：它从一批设计资料里找证据再回答，
> 每条结论会标「直接证据 / 间接证据」，**证据不够的时候它会直接说"不足以回答"，而不是编一个**。
>
> 现在库里的资料主要在这几块：
> - 法规标准：GB 4806 系列（食品接触塑料/金属/陶瓷/橡胶）、EU 食品接触、FDA、GB/T 3326 家具、人体尺寸标准
> - 材料数据：PC/LEXAN、Tritan、PP、PPSU、玻璃、不锈钢 304 的技术数据表
> - 人因数据：中国成年人/儿童人体尺寸、手部尺寸与握力
> - 制造工艺：注塑 DFM、吹塑、Tritan 加工指南
> - 另外有一批**我自己写的设计规则**（现在基本是水杯品类的）
>
> 两件事先说清楚：
> 1. **它不快。** 第一次问一道没问过的问题，最长要等 3~4 分钟；同一道题再问一次只要 0.2 秒。
> 2. **它答不出来是正常的，而且正是我想知道的。**
>    我在找它**答不出**和**答错**的地方——所以请**不要**特意挑"看起来它能答"的问题，
>    也不要为了照顾我而说"挺好的"。你问倒它，对我价值最大。
>
> 我会把你的问题原文记在项目文档里（会去掉你的名字）。如果某道题不方便记录，跟我说一声就行。

## 3. 阶段 1 提问脚本（无提示，**先做**）

> 先别管这个系统。回想**过去一个月**，你在做设计、作业或者项目的时候，
> 有没有为了确认一个事实去翻资料、问人或者搜网页？比如某个标准怎么规定、某种材料能不能用、
> 某个尺寸该取多少、某个工艺会不会出问题。

请他写 **3~5 个当时真的想问的问题**，并填右边的信息：

| # | 问题原文（越具体越好：带标准号 / 材料牌号 / 尺寸 / 产品） | 当时怎么解决的 | 花了多久 | 得到确定答案了吗 |
| --- | --- | --- | --- | --- |
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |

**引导话术（只在对方卡住时用，不要提前给）**

- "不用是特别难的问题，你上周查过的也算。"
- "你当时是翻了哪份资料？还记得文件名或者标准号吗？"
- "如果当时没查到，你最后是怎么决定的？"

⚠️ **三条禁令**：不要展示资料清单、不要打开系统给他看、不要在他写阶段 1 之前提"我们库里有 XX"。

## 4. 阶段 2 提问脚本（给过 §2 简介之后）

> 现在你知道它大概有什么了。**如果它就在手边，你会拿它问哪几个问题？**
> 也欢迎问那些你觉得它大概率答不出的——我想知道边界在哪。

记录方式同 §3，但**标注来源阶段 = 2**。

## 5. 逐题采集表（空白模板）

一人一份，每题一行：

| 字段 | 填什么 | 示例 |
| --- | --- | --- |
| `问题原文` | 一字不改 | `GB/T 16252—2023 的适用范围包括儿童吗？` |
| `来源阶段` | `1` 无提示 / `2` 有提示 | `1` |
| `场景` | 在做哪个产品 / 作业 | `毕设：儿童餐椅` |
| `期望答案形态` | 一个数值 / 一段规则 / 多方案对比与推荐 / 可复现的推导 / **正确的拒答** | `一段规则` |
| `需要哪类来源`（对方填） | 标准 / 材料 TDS / 工艺指南 / 人因数据 / 经验规则 / 不知道 | `标准` |
| `显式标识符` | 标准号、牌号、尺寸、文件名——有的话非常关键 | `GB/T 16252—2023` |
| `当时怎么解决的` | 翻纸/PDF、问同事、搜网页、凭经验 | `搜网页，看到一份二手解读` |
| `当时耗时` | 大致分钟数 | `约 40 分钟` |
| `是否愿意实测` | 是 / 否 | `是` |
| `可否记录原文` | 是 / 否（否 → 只记哈希） | `是` |
| `受访者代号` | 不要真名，用 `U1`~`U5` | `U2` |

**期望答案形态这一栏别省。** 「多方案对比与推荐」和「一个数值」是两种完全不同的能力，
前者要跨来源合成，后者一次检索就够——把这两类混在一起统计，任何结论都站不住。

## 6. 我这边要填的分析字段

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `现在能不能答` | 可交付 / 部分 / 拒答 | 实际跑一次，不要凭感觉判 |
| `实际检回了什么` | 来源文件名 + 排名 | 用于区分"没检到"和"检到了没用" |
| `缺口类型` | `R1` 来源不在库 / `R2` 在库但检不到 / `R3` 检到了但生成漏项 / `R4` 检索到但排太后 / `R5` 缺规则文件 / `M1` 其实是判据问题 | 分类法与 PRD §7 同源 |
| `缺口是否可修` | 可（补资料即可）/ 需改检索 / 机制性问题 | 「机制性问题」指任何深度都检不到的那一类 |
| `是否进补资料清单` | 是 / 否 + 优先级 | 优先级见 §8 |

## 7. 落盘格式

一行一题，存 `data/research/question_intake.jsonl`（`data/` 已 gitignore，原始问题不外传）：

```json
{"id":"U2-Q3","participant":"U2","stage":1,"question":"...","product":"儿童餐椅",
 "expected_form":"规则","needs":["standard"],"identifiers":["GB/T 16252—2023"],
 "current_practice":"搜网页","minutes_spent":40,"answerable":"拒答",
 "retrieved":[], "gap":"R1","fixable":"可","in_backlog":true,"priority":2,
 "recorded_verbatim":true,"collected_at":"2026-10-22"}
```

## 8. 怎么用这些数据（缺口优先级）

对**阶段 1 的题**做统计，只有三个数：

1. **缺口出现的次数**（同一个来源被两题以上需要 → 直接进清单）
2. **题型集中度**（数值型 / 规则型 / 对比型各占多少——决定该补 TDS 还是补规则）
3. **机制性缺口占比**（`R2` 那种"在库但任何深度都检不到"的，补资料没用，要改检索）

粗排：`优先级 ∝ 出现次数 × 是否核心场景 × (1 − 已有替代来源)`

⚠️ **一个反直觉的预期**：按项目已有的测量，最可能的结果不是"缺资料"，而是
**"资料在库、但检不到或没被用上"**（16 条来源任何深度都检不到；77.6% 的 chunk 没有角色标签）。
如果阶段 1 的数据也是这样，**结论就是先修检索，而不是先买资料**——这与 [backlog-rice.md](backlog-rice.md) 的排序一致。

## 9. 已知局限

- **样本无代表性**：5 个同学，方便抽样，不能声称代表"设计师群体"。
- **只做描述**：25 题不构成任何统计检验的基础，结论写成"这 5 个人里有 3 个…"，不写"68% 的设计师…"。
- **我自己在场会污染**：我在旁边解释系统，对方的提问会被我影响 → 尽量让阶段 1 在他独立完成后再介入。
- **"当时耗时"是回忆值**，不是测量值，只能当量级用（分钟级），不要当成指标。
- 阶段 1 的题**天然偏向他已经查过的东西**——真正被他放弃、连查都没查的问题，这张表收不到。
  这是问卷法固有的盲区，不是执行失误。
